# daily-challenges

One small programming puzzle a day, solved in Python.

Each directory is named for the date of the puzzle (`YYYY-MM-DD`) and holds a single
`app.py`: the puzzle statement as a comment block at the top, the solution below it,
and a few worked examples at the bottom.

```
2026-09-12/app.py   The Tap-Room Slate
2026-09-16/app.py   The Beacon-Keeper's Oil Ledger
2026-09-17/app.py   The Tollhouse at Mirebridge
2026-09-18/app.py   The Lanterns of Dusk Lane
2026-09-19/app.py   The Ferryman's Tally Board
2026-09-20/app.py   The Cistern-Keeper's Tally at Tidewell
2026-09-21/app.py   The Tollhouse Permit Desk
```

Run any of them directly:

```sh
python 2026-09-21/app.py
```
